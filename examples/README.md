# Demo papers

The repository ships no papers. To try Amelia with documents you are allowed to share, use open-access papers under a CC BY license.

- [PLOS](https://journals.plos.org) publishes every article under CC BY 4.0. Download the PDF from the article page.
- On arXiv, check each paper's license: only papers marked CC BY can be shared freely.

When you share a dataset made from a CC BY paper, credit the paper: title, authors, DOI and license.
